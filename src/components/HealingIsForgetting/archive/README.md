# Healing Is Forgetting – feature film archive

Healing Is Forgetting started as a feature film (Jan–Jun 2026). In September 2026
it became a short film, and the feature-film material was moved here.

- `synopses.js` – synopsis versions v1.0 (Jan 2026) to v5.0 (Jun 2026)
- `treatment.js` – treatment versions v1.0 (Mar 2026) to v4.0 (Jun 2026)
- `FeatureFilmArchive.js` – the old logline, project status and idea board,
  plus the synopses and treatments above, as shown on the page until June 6, 2026

It is still shown on `/healingisforgetting` (behind the password) in the
"Archive" section.
